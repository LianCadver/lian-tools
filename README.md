A lightweight, local-first toolbox for reading, text processing, encoding, and productivity utilities, built entirely with vanilla HTML, CSS, and JavaScript.

## Included Tools
 * **Readflow:** A text revealer tool that allows you to read pasted text at a customizable, controlled pace. Includes progress saving.
 * **Streamcord:** A utility to generate fixed embed URLs for Discord. Supports platforms like Twitter/X, Instagram, Pixiv, Reddit, TikTok, Bilibili, and more.
 * **Text Editor:** A scratchpad featuring live character, word, and line counts. Includes quick actions for case conversion (uppercase, lowercase, title case, snake_case, kebab-case) and line cleanup.
 * **Encode & Decode:**
   * Base Converter (Decimal, Binary, Octal, Hexadecimal, ASCII text)
   * Base64 encoder/decoder
   * URL encoder/decoder
   * HTML Entity encoder/decoder
 * **Link Cleaner:** Automatically strips tracking parameters, UTM codes, and other unnecessary data from URLs.
 * **Kanban Board:** A drag-and-drop task management board featuring customizable columns, colour-coded labels, deadlines, and attachments.

## Core Features
 * **Local Storage:** All preferences, drafts, and tool states are saved locally in your browser via localStorage. No data is sent to a server.
 * **Data Management:** You can export all your data (including Kanban tasks and tool preferences) as a JSON file and import it across devices.
 * **Customization:** Includes light and dark themes, as well as a customizable hub dashboard where you can search, sort, and pin your frequently used tools.

## Usage
Because Lian Tools is built with vanilla web technologies and relies strictly on client-side storage, no build steps or local servers are required.
 1. Open from https://liantools.pages.dev
 2. Or download repository as a .zip file, extract to a folder and run index.html in any modern web browser

## Privacy
Lian Tools runs entirely in your browser.
No accounts, analytics, or servers are required.
Your data never leaves your device unless you export it manually.
